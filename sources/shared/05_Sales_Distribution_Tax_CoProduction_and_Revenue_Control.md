# Saracen Bridge Analytics — Sales, Distribution, Tax, Co-Production and Revenue Control

**Version:** V2.0  
**Effective date:** 28 August 2026  
**Status:** Corrected and consolidated internal methodology  
**Use:** Saracen Bridge Film Finance Analyst — film and television greenlight, closing, underwriting and monitoring

> This is an internal analytical and control framework. It is not legal, tax, accounting, insurance, completion-bond or investment advice. Appropriate professional advisers must review specialist matters. Current law, regulation, incentive rules, market terms, insurance, bonding, lender appetite and counterparty strength must be verified for each assessment.

## Controlling application rules

Separate commercial value from debt collateral. Sales estimates, incentives and treaty benefits require current verification and must not be treated as contracted cash. Underwrite headline amounts to net eligible, enforceable, assignable and collectible value after fees, caps, deductions, timing, currency and counterparty risk. Verify collection and payment-direction controls.

## Incorporated methodologies

## Tax Incentive Underwriting Guide

### 1. Purpose
This guide sets the underwriting method for government production incentives, rebates, credits and grants.

It intentionally does **not** hard-code statutory rates. Tax incentive legislation, eligibility, caps, application requirements and payment timing change. Current rules must be verified for every transaction from authoritative or specialist sources.

### 2. Fundamental rule
The analyst must distinguish:

**Headline statutory rate**  
from  
**project-specific effective incentive**  
from  
**lender-underwritten net receivable**.

They are not the same number.

### 3. Required incentive data
For each incentive record:
- jurisdiction;
- programme name;
- administering body;
- type: refundable credit / rebate / grant / transferable credit / offset;
- statutory basis;
- effective date checked;
- qualifying applicant;
- cultural / content test;
- production threshold;
- local spend requirement;
- qualifying expenditure;
- excluded expenditure;
- cap;
- uplift;
- regional component;
- labour limitations;
- related-party rules;
- audit;
- certification;
- filing;
- payment timing;
- assignability;
- security;
- tax set-off;
- recapture;
- currency.

### 4. Evidence hierarchy
#### Strong
- specialist incentive opinion;
- recognised production accountant calculation;
- eligibility / interim certificate;
- official programme confirmation;
- executed local production structure;
- detailed qualifying cost report.

#### Medium
- detailed producer calculation tied to budget;
- specialist memo not yet final;
- draft application.

#### Weak
- headline percentage in pitch deck;
- marketing brochure;
- verbal statement;
- budget line with no qualifying-cost analysis.

### 5. Calculation framework
Start with the locked production budget.

Then:
1. identify qualifying spend;
2. remove excluded costs;
3. apply jurisdiction-specific rules;
4. apply caps / uplifts;
5. consider related-party adjustments;
6. estimate audit / compliance costs;
7. consider tax offsets or withholding;
8. convert currency only where necessary using a stated assumption;
9. model payment timing;
10. apply lender haircut.

The report should state both:
- gross estimated incentive;
- net underwritten collateral value.

### 6. Advance framework
As an internal starting point, a highly verified, assignable incentive with credible timing may support a relatively high advance. Reduce the advance for:
- uncertain eligibility;
- first-time applicant complexity;
- weak documentation;
- long payment delay;
- audit exposure;
- recapture risk;
- transferability issues;
- inability to assign;
- currency risk;
- budget volatility.

Do not use one universal percentage across all jurisdictions.

### 7. Timing risk
Model:
- production start;
- qualifying spend period;
- audit;
- filing;
- provisional / final certificate;
- tax return if applicable;
- administrative processing;
- expected cash receipt;
- downside delay.

Include an interest reserve where the incentive may be delayed beyond base case.

### 8. Security and assignment
Determine:
- whether the receivable can be assigned;
- whether security can be registered;
- whether government acknowledgement is available;
- whether a lender can control the receiving account;
- whether the credit is payable only to the taxpayer;
- whether transfer or sale is permitted;
- whether the production entity must remain solvent / active;
- whether tax liabilities can offset the refund.

### 9. Recapture and clawback
Assess risks from:
- non-completion;
- failure of cultural test;
- inaccurate cost classification;
- related-party charges;
- late filing;
- insufficient local spend;
- changed ownership;
- non-compliance with labour requirements;
- audit adjustment;
- fraud / misrepresentation;
- programme suspension or legal change.

### 10. Jurisdiction review template
For each jurisdiction prepare:

| Field | Entry |
|---|---|
| Programme | |
| Effective date verified | |
| Headline mechanism | |
| Qualifying entity | |
| Minimum spend | |
| Qualifying costs | |
| Exclusions | |
| Cap | |
| Uplifts | |
| Application timing | |
| Audit / certification | |
| Expected payment timing | |
| Assignment / security | |
| Currency | |
| Key risks | |
| Underwritten net amount | |
| Proposed advance | |

### 11. Documentation checklist
- official programme rules;
- specialist tax / incentive memo;
- production accountant calculation;
- qualifying budget;
- application;
- cultural test materials;
- interim / final certificate;
- audit engagement;
- tax filings;
- tax clearance where relevant;
- assignment / security documents;
- bank account evidence;
- payment history if refinancing a receivable.

### 12. Report language
Avoid:
- “The production will receive X” unless eligibility is confirmed.
- “Guaranteed tax credit” unless legally and factually justified.
- “Bankable at the headline rate.”

Prefer:
- “The producer estimates…”
- “Subject to verification of qualifying expenditure…”
- “The lender-underwritten receivable is expected to be lower than the headline estimate because…”
- “Unable to verify current eligibility based on the information supplied.”

### 13. Required web verification
For every live assessment involving a tax incentive, verify current programme rules at the date of analysis. Priority should be given to:
- government / administering authority;
- statutory or official guidance;
- recognised specialist tax / production finance advisers;
- reputable legal or accounting commentary where needed.

Record the date checked.

## Sales, Distribution and MG Bankability Framework

### 1. Purpose
This framework separates commercial market evidence from debt-finance collateral and defines how Saracen Bridge Analytics should assess international sales, distribution agreements, minimum guarantees, pre-sales, platform licences and related receivables.

### 2. Evidence ladder
From strongest to weakest:

1. Executed licence / distribution agreement with firm payment obligation.
2. Executed MG or pre-sale subject to manageable delivery conditions.
3. Binding term sheet with limited remaining documentation.
4. Non-binding term sheet / LOI.
5. Sales agent estimates.
6. Distributor expression of interest.
7. Producer expectation.
8. Market speculation.

Only the top categories normally support senior receivable lending.

### 3. Sales agent review
Assess:
- company history;
- leadership;
- genre expertise;
- relevant sales;
- buyer relationships;
- current slate;
- territory coverage;
- estimation methodology;
- fee;
- expenses;
- term;
- exclusivity;
- termination;
- collection;
- reporting;
- audit;
- cross-collateralisation;
- advance / MG if any.

Sales estimates are evidence of market opinion. They are not contractual receivables.

### 4. Distribution agreement review
Record:
- distributor;
- territory;
- rights;
- media;
- term;
- licence fee / MG;
- currency;
- deposit;
- delivery payment;
- acceptance;
- delivery materials;
- release obligation;
- marketing commitment;
- fees;
- expenses;
- recoupment;
- reporting;
- audit;
- termination;
- assignment;
- collection account;
- governing law.

### 5. MG bankability test
Ask:
1. Is the agreement executed?
2. Is the MG fixed?
3. Is the counterparty creditworthy?
4. Are payment triggers objective?
5. Can the counterparty terminate before payment?
6. Are there material offsets?
7. Is the receivable assignable?
8. Can the lender receive notice / acknowledgement?
9. Is payment routed to a controlled account?
10. Are delivery requirements achievable?
11. Is the currency hedged or haircutted where necessary?
12. Is the MG already pledged elsewhere?

### 6. Pre-sale bankability
A pre-sale should be discounted where:
- buyer is small or opaque;
- payment is heavily back-ended;
- delivery specifications are unusually burdensome;
- acceptance is subjective;
- cast conditions are not satisfied;
- censorship approval is a condition;
- distributor can terminate for broad commercial reasons;
- receivable cannot be assigned;
- territory rights conflict with another agreement;
- buyer deposit has not been paid when expected.

### 7. Platform / streamer licences
Assess separately from theatrical distribution.

Review:
- exclusivity;
- global / territory rights;
- window;
- term;
- buyout economics;
- delivery;
- technical acceptance;
- marketing obligations;
- holdbacks;
- sequel / derivative restrictions;
- payment;
- termination;
- content compliance;
- publicity;
- assignment.

A large licence fee is not automatically high-quality collateral if termination and acceptance rights are broad.

### 8. Distributor quality
Use qualitative grading based on current evidence:

#### Grade A
Major institutional or highly established counterparty with strong payment confidence.

#### Grade B
Established independent distributor with credible financial and operating history.

#### Grade C
Smaller, newer or less transparent buyer requiring reduced reliance, deposit, guarantee or additional controls.

#### Grade D
Weak, disputed or unverified counterparty. Generally unsuitable as senior repayment collateral without enhancement.

Do not hard-code a company permanently into a grade. Counterparty quality must be current.

### 9. Sales estimates
A sales estimate should show:
- territory;
- low / base / high where justified;
- rights basis;
- cast assumptions;
- genre;
- budget band;
- comparable titles;
- timing;
- distributor fee;
- expenses;
- collection costs;
- currency;
- unsold / sold status.

Never include sold territories in the unsold gap base.

### 10. Gap finance methodology
Start with conservative unsold sales value.

Then deduct:
- sales agent commission;
- sales expenses;
- collection costs;
- delivery reserves;
- local distribution deductions where applicable;
- currency haircut;
- market deterioration haircut;
- senior claims;
- already contracted territories;
- disputed or low-confidence territories.

Apply a low advance to the resulting conservative base.

Gap finance should not be used to disguise a structural equity shortfall.

### 11. Commercial value versus collateral value
Example classifications:

| Item | Commercial value | Debt collateral |
|---|---|---|
| Strong sales estimate | Yes | No |
| A-list cast interest | Potentially | No |
| Executed MG | Yes | Potentially |
| Executed platform licence | Yes | Potentially |
| Distributor LOI | Some | Usually no |
| Territory pre-sale | Yes | Potentially |
| Festival acceptance | Marketing value | No |
| Awards potential | Possible upside | No |
| Producer forecast | Indicative only | No |

### 12. Collection and control
For debt-supported distribution receivables consider:
- collection account management agreement;
- irrevocable payment direction;
- notice of assignment;
- distributor acknowledgement;
- lender security;
- blocked account;
- waterfall;
- reporting;
- audit;
- payment currency.

### 13. Required report table
| Territory / Rights | Buyer | Contract status | Gross value | Net value | Credit grade | Payment timing | Assignment | Proposed advance | Key risk |
|---|---|---|---:|---:|---|---|---|---:|---|

### 14. Red flags
Escalate:
- unsigned “deal” described as committed;
- sales estimate treated as cash;
- distributor MG net of unspecified expenses;
- buyer not legally identified;
- payment due only after theatrical performance;
- unrestricted termination right;
- delivery dependent on unfinanced reshoots;
- no assignment right;
- competing territory grants;
- rights term inconsistent with chain of title;
- recoupment waterfall obscures lender priority;
- distributor or sales agent has material litigation / solvency concerns;
- buyer deposit overdue.

### 15. Conclusion framework
State separately:
- commercial sales strength;
- amount of executed contracted value;
- amount considered potentially bankable;
- indicative debt capacity;
- unsold market value;
- gap-finance potential;
- principal conditions precedent;
- confidence level.

## Co-Production and Treaty Finance Guide

### 1. Purpose
This guide provides a framework for assessing official and non-official co-productions and cross-border film finance structures.

Treaty and incentive rules are time-sensitive and must be verified with current official guidance and specialist counsel.

### 2. Distinguish structure types
Identify whether the project is:
- official treaty co-production;
- domestic co-production;
- production services structure;
- minority co-production;
- SPV + service company;
- non-treaty cross-border financing structure.

### 3. Core questions
Assess:
- which entity owns rights;
- which entity is lead producer;
- which entities incur spend;
- which incentives each entity claims;
- financing contributions;
- creative contribution;
- personnel requirements;
- nationality tests;
- spend tests;
- rights allocation;
- revenue split;
- security structure;
- governing law.

### 4. Official co-production
Review:
- applicable treaty;
- competent authorities;
- provisional approval;
- final approval;
- minimum / maximum participation;
- creative contribution;
- technical contribution;
- national elements;
- spend requirements;
- rights allocation;
- recoupment.

### 5. Finance interaction
Test:
- whether each incentive can coexist;
- whether one jurisdiction's finance is conditional on treaty approval;
- timing of approvals;
- cashflow;
- bridge finance;
- currency;
- withholding;
- transfer pricing;
- intercompany charges.

### 6. Rights and recoupment
Clarify:
- copyright ownership;
- exploitation rights;
- territory splits;
- revenues;
- collection account;
- producer shares;
- lender security;
- investor priority.

### 7. Cross-border risks
Consider:
- FX;
- withholding;
- VAT/GST;
- local labour;
- immigration;
- sanctions;
- political risk;
- bankability of local receivables;
- enforceability;
- local security perfection;
- insolvency regimes.

### 8. Documentation
Review:
- co-production agreement;
- treaty application;
- provisional certificate;
- finance plan;
- budget allocation;
- intercompany / services agreement;
- IP licences;
- distribution rights;
- collection account;
- intercreditor;
- tax / incentive opinions.

### 9. Red flags
Escalate:
- treaty status assumed but not approved;
- creative contribution does not meet requirements;
- spend allocation inconsistent with incentive claim;
- rights split conflicts with sales agreements;
- one producer is undercapitalised;
- currency exposure unhedged;
- security cannot be perfected across jurisdictions;
- finance depends on incompatible incentive rules.

### 10. Conclusion
State:
- structural viability;
- approval status;
- finance dependency;
- cross-border risks;
- required specialist verification;
- conditions before financing.

## Collection Account and Revenue Control Guide

### 1. Purpose
This guide defines the control framework for film and television revenues where lenders and investors rely on centrally administered collections.

### 2. Core objective
Ensure that contracted and exploitation revenues:
- are paid to the correct account;
- cannot be redirected unilaterally;
- are distributed according to an agreed waterfall;
- are transparent;
- are auditable.

### 3. Collection structures
Assess:
- collection account management agreement;
- blocked account;
- escrow;
- distributor direct-pay;
- notice of assignment;
- account control agreement.

### 4. Collection account manager
Assess:
- independence;
- experience;
- jurisdiction;
- reporting;
- fees;
- authority;
- dispute process;
- ability to implement waterfall.

### 5. Required payment directions
For material receivables:
- identify payor;
- amount / rights;
- payment date;
- account;
- assignment;
- acknowledgement;
- irrevocability where possible.

### 6. Waterfall controls
The CAMA / account documents should align with:
- lender priority;
- investor priority;
- distributor recoupment;
- sales agent fees;
- residuals;
- producer participations;
- reserves.

### 7. Leakage risks
Escalate:
- distributor pays producer directly;
- sales agent controls receipts without lender acknowledgement;
- uncapped expenses paid before debt;
- related-party payments ahead of investors;
- multiple collection accounts;
- territory revenues outside the CAMA;
- amendments allowed without lender consent.

### 8. Reporting
Require:
- receipts statement;
- disbursement statement;
- territory;
- payer;
- invoice;
- FX;
- fees;
- expenses;
- reserve;
- balance.

### 9. Audit
Confirm:
- inspection rights;
- audit frequency;
- records retention;
- dispute process;
- underpayment recovery.

### 10. Conditions precedent
Potential CPs:
- CAMA executed;
- all material buyers notified;
- assignments acknowledged;
- collection account open;
- waterfall tested;
- lender security perfected.

### 11. Conclusion
State:
- whether revenue control is adequate;
- leakage risk;
- priority clarity;
- required amendments;
- confidence.
